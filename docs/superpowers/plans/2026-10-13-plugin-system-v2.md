# Система плагинов v2: скрипты, репозитории, панель

Дата: 2026-10-13

## Что не так сейчас

Плагин — это запись в таблице `src/plugins.cpp` с «видом» действия (`gpio`,
`screen`, `http`, `weather`, `tuya`), скомпилированным в прошивку. Добавить
**новую возможность** = правка нескольких файлов + пересборка и перепрошивка.

## Что хотим

1. Плагин — **файл-скрипт**, а не код в прошивке.
2. Плагины качаются из **репозиториев** по адресам из `config.h`.
3. На стике — **панель плагинов** (в меню настроек): список, установка,
   удаление, отметка «есть версия новее».
4. Открывается **потряхиванием** стика.
5. Добавить плагин = положить два файла в репозиторий. Прошивку не трогаем.

## Решения

- **Язык.** Свой крошечный интерпретатор чистым модулем (`src/pure/script.h`,
  готов, 56 проверок). Не Berry и не Lua: чужая интеграция в сборку и риск
  зависаний. Скрипт ограничен белым списком функций хоста — скачанный плагин
  ничего лишнего сделать не может.
- **Формат плагина** — сам скрипт; метаданные в шапке из комментариев:
  ```
  # name: switch
  # description: Включить, выключить или переключить выключатель
  # params: channel=1|2|3|all, state*=on|off|toggle
  ```
  `*` после имени — параметр обязательный; значения через `|` дают enum.
- **Репозиторий** — публичный, с манифестом `index.txt` (наш блочный формат)
  и файлами `.ais` рядом. Манифест, а не листинг каталога: работает на любом
  хостинге и разбирается уже готовым парсером.
- **Источники** — список URL в `config.h`.
- **Хранение установленного** — LittleFS: `/plugins/<name>.ais` +
  `/plugins/installed.txt` (имя, источник, версия).
- **Офлайн** — манифесты кэшируются в LittleFS; нет сети — работаем кэшем.
- **Ошибки скрипта изолированы**: не выполнился — короткая причина на экране,
  остальные плагины работают. Лимит шагов против вечных циклов.

## Фазы

### ✅ F1. Метаданные и манифест (чистые модули)
- `src/pure/plugin_meta.h` — шапка скрипта → имя, описание, JSON-схема аргументов.
- `src/pure/plugin_repo.h` — разбор `index.txt` (имя, описание, файл, версия).
- Тесты на оба.

### ✅ F2. Хост скрипта (прошивка)
- `src/script_host.cpp` — функции, доступные скрипту:
  `http`, `proxy_post`, `json`, `gpio` (белый список пинов), `show`, `log`,
  `sleep`, `len`, `str`, `num`.
- `src/plugins.cpp` переписывается: плагины — это установленные `.ais`,
  таблица инструментов собирается из их шапок, вызов = запуск скрипта с
  аргументами в переменных.

### ✅ F3. Загрузка из репозиториев
- `src/repo.cpp` — скачать манифесты, сложить в LittleFS, сравнить версии.
- Список источников — в `config.h`.

### ✅ F4. Панель и меню настроек
- Меню настроек (первый пункт — «Плагины»), навигация кнопками.
- Панель: один список со отметками «установлен / есть новее», BtnA —
  поставить/удалить, удержание — выход.

### ✅ F5. Потряхивание
- Детектор тряски по акселерометру (M5.Imu) с кулдауном; открывает меню.

### ✅ F6. Миграция и документация
- Перевести `switch`, `weather`, `show_text`, `lamp` на скрипты.
- Репозиторий плагинов (отдельный) + описание формата в README.

## Порядок

F1 → F2 (без них панель нечего показывать) → F3 → F4 → F5 → F6.
Каждая фаза — отдельный коммит с тестами.
